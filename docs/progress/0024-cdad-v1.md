# 0024 - Certified Decision-Adaptive Dyadic v1

Date: 2026-08-30. State: off-circuit matrix, signed decision R1CS and
fixed-precision Nova prototype completed.

## Objective and state

Turn the CBD precision chain into a public, deterministic, decision-adaptive
representation. The controller must reduce unnecessary linked retries without
participating in the soundness decision.

## Files and interfaces

- `numeric-core/src/cdad.rs`: profile, `(M,R,F,profile_id)` state, policies,
  selections and adaptive result.
- `numeric-core/src/profile.rs` and `frontier.rs`: CDAD family, adaptive bound,
  schema v2 and three canonical representations.
- `frontier_eval.rs`: all four workloads plus adaptive metrics.
- `nova-circuit`: fixed-precision CDAD wrapper, signed inner-product gadget and
  `cdad-cost` measurement.
- `build_pareto.py`: measured adaptive cost and three-dimensional dominance.
- `docs/cdad-mathematical-specification.md` and `docs/cdad-protocol.md`.

## Decisions

The directed controller may inspect higher-precision certified enclosures
locally before choosing the next proof. It never inspects the exact reference.
Only actual proof attempts and links enter constraint cost. Fixed precision
inside one Nova instance is constrained as state; profile changes remain linked
proofs in v1.

## Evidence

- Reduced exhaustive test: three policies, 65 inputs, four horizons and three
  thresholds, with no incorrect definitive result.
- ECEF: fixed CDAD-16 decides 838/2,000; sequential and directed decide 2,000.
  Directed removes nine 32-bit proof attempts and nine links relative to the
  sequential ladder.
- Adult: fixed decides 1,856/1,857; both adaptive policies decide all cases.
- Measured fixed circuit costs: 419, 711, 1,003 and 1,295 constraints for
  16/32/48/64 bits. Precision selection adds exactly two constraints.
- The ECEF three-term score costs 1,386/2,170/2,954/3,738 constraints and the
  Adult six-term score costs 2,571/4,027/5,483/6,939 constraints.
- Nova CDAD-32: 711 raw constraints, 12,089 primary constraints, 10-fold
  compressed proof of 10,784 bytes.
- Unified coverage: 794 records, of which 60 are CDAD; Pareto join 754/794
  (95.0%). Directed CDAD is non-dominated for ECEF and dominates sequential
  CDAD at identical soundness and availability.

## Failed or limited attempts

A radius/margin prediction alone selected 32 bits almost universally and did
not save links. Speculative certified recomputation was added so the prover can
skip profiles that are known locally to remain indeterminate.

The cost sweep still lacks homogeneous Adult/ECEF circuits for the older
families. CDAD now uses workload-specific measured dot-product costs, while
those older decision-family records remain coverage-only orphans. The existing
link circuit commits a scalar encoding; a specialized vector commitment for all
Adult/ECEF features remains a protocol integration task and is not claimed as
completed.

## Next step

Run the prepared 30-round interleaved timing protocol including CDAD, then add
a vector commitment/link gadget for the decision workloads. Heterogeneous Nova
adaptation remains a later phase.

## Continuity instruction

Do not treat speculative evaluations as proof attempts. If the CDAD cost model
changes, regenerate `cdad_precision_cost.json`, `escalation_link_cost.json`,
`frontier_coverage.json` and the Pareto outputs in that order. Preserve schema-v1
hashes: only builders using `.adaptive(...)` may emit schema v2.
